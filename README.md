One line that gives Uranus a funny new name — "The Napper" — and says why in
the same breath: it orbits tipped 98 degrees on its side, each of its seasons
lasts 21 years, and it still will not get out of bed.

## Run

```sh
python3 main.py
```

Writes the single entry line to `entry.txt` inside the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`), with no trailing newline.
